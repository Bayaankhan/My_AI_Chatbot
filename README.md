## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Bayaankhan/My_AI_Chatbot.git
```

### 2. Navigate to the project directory

```bash
cd My_AI_Chatbot
```

### 3. Install dependencies

If your project contains a `requirements.txt` file, run:

```bash
pip install -r requirements.txt
```

### 4. Run the chatbot

If the main file is named `app.py`, run:

```bash
python app.py
```

If your main file has a different name, use that filename instead.
